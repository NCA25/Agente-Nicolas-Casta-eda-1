# Agente de Mercadeo y Ventas (Gemini)

Agente de IA en HTML + JavaScript que usa la API gratuita de Gemini, con búsqueda web y fuentes.

## Estructura
- `index.html`: interfaz
- `css/styles.css`: estilos
- `js/config.js`: modelo y opciones
- `js/prompt.js`: instrucciones del agente
- `js/app.js`: lógica y llamadas a la API

## Uso
1. Crea una API key gratis en https://aistudio.google.com/apikey
2. Abre la página (GitHub Pages o `index.html` local) y pega la key cuando la pida.
   La key se guarda solo en tu navegador. Nunca la escribas en los archivos ni la subas a GitHub.

## Nota
Cada persona que use tu página debe poner su propia key.
